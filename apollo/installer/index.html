Apollo MLED-1 Installer

Connect the MLED-1 to this computer with a USB cable, then press Install. This needs a browser with Web Serial, such as Chrome or Edge.

MLED-1 firmware @VERSION@

After installing

The installer can connect the MLED-1 to Wi-Fi straight away over USB. If you skip that, join the open Wi-Fi network Apollo MLED-1 Hotspot and browse to 4.3.2.1 to set it up.
